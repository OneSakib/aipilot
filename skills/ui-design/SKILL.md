- Define design tokens first: a small color palette, a type scale, spacing steps and radii. Reuse them everywhere.
- Pick one display font and one text font. Keep body text at 16px or larger with generous line height.
- Establish clear hierarchy: one primary action per view, strong headings, quiet secondary text.
- Build mobile first and scale up with flexbox or grid. Test narrow and wide widths.
- Support dark mode through color variables, and keep contrast at WCAG AA or better.
- Use subtle motion for feedback only, and respect `prefers-reduced-motion`.
- Design real empty, loading and error states instead of leaving them blank.
