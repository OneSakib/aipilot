# Project guide

## Code rules
- Write optimized, readable code that a person would write by hand.
- Do not add comments or docstrings.
- Organize code directory-wise: one responsibility per file, so any file can be changed on its own.
- Use clear names instead of explanations.
- Make sure every change runs. Execute the tests or a quick check before finishing.

## Workflow
- Read related files before editing.
- Keep changes small and focused on the request.
- Reuse existing helpers and follow the patterns already in the project.
